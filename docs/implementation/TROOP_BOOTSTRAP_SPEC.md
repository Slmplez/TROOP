# TROOP 独立启动与工作区基础闭环

用户于 2026-11-01 明确要求继续开发。本规格交付不依赖暂停的沙箱工作的独立基础能力，使用已确认的 Core/IPC/生命周期与本地集成决策；不把未完成的双环境契约视为已解决。

## 交付

- 新 Electron main/preload/React 入口和独立包依赖，不复制旧应用入口、bundle、Setup 或私有运行时。
- Rust workspace：protocol、storage、core。Core 是 SQLite 的唯一写入者，数据目录有独占锁和 schema 版本检查。
- 有界 JSON-RPC 行协议，握手、版本、generation、请求 ID、超时与明确错误；不暴露任意方法、路径或命令执行接口。
- 工作区选择、持久化、重命名和移除登记；移除登记不删除原目录或文件。
- Core 启动/故障状态可见，用户可手动重启；旧 generation 的请求拒绝且不重放。
- 单实例、关闭到托盘、托盘恢复、明确退出与 Core 有界停机。主进程死亡导致 stdin EOF，Core 退出释放存储锁。

## 验收

1. 从官方 Electron npm 分发与锁定 Cargo/npm 依赖独立启动；记录来源及版本。
2. 真实 Rust 进程完成握手及工作区持久化；重启仍有相同登记，移除登记保留文件。
3. 坏消息、超大帧、未知方法、重复 ID、版本不匹配、未握手和旧 generation 不产生非预期写入。
4. Core 崩溃后 pending 请求终止，恢复不自动重发；旧进程迟到 close 不破坏新进程状态。
5. 界面有真实加载、空、错误与恢复状态；IPC 校验调用方和参数，Renderer 无 Node 访问。
6. 关闭窗口保持托盘与 Core，显式退出后无所属 Core 孤儿进程；第二实例不产生第二个写入者。

模型对话、Agent 工具、记忆、Skills、MCP、网关路由和自动化将在后续功能包实现。本基础版本不显示伪造模型回复，不代表核心完整首版交付。未来产品的商标与图标完善、签名安装包和干净机器验证不由开发启动检查替代。
