Git 权限回归使用工作区内伪装的同名程序，以及配置了 fsmonitor/过滤器的自有仓库，确认 Git 程序来自工作区外、fsmonitor 被禁用，且 Git 工具在批准前不会建立 Worker 或执行仓库程序。批准后查询通过；不把 Git 命令宣称为不会产生外部效果的纯文件读取。

实际终止 Core 与实际命令进程树，核对 Node 子孙 PID 停止及心跳文件不再增长；正常前台命令结束后遗留的子进程也会在资源释放前清理。Core 通过 Job 的 ActiveProcesses=0 确认整棵受管树退出，确认先写回执再交出执行资源。重启后不发模型请求，未核对的未知结果不能继续。显式退出保存 interrupted；停止保留既有产物。Worker 最终回执保留而 Core 检查点回退的隔离故障注入，验证只接纳原结果、不重跑旧命令；回执仍标记不确定时拒绝直接继续。SQLite 提交触发器故障验证派发前提交失败时没有 Worker 或文件效果。故障注入仅修改自有测试数据库。

## 用户所选真实服务

用户已保存的 Anthropic Messages 服务，在独立验收目录中实际完成 write_file 创建固定测试文件 → read_file 读取 → 模型总结，共 3 个模型步骤、2 次成功工具；写入只批准精确匹配的文件名、内容和版本参数。重启后任务 completed、工具 ID 和模型步骤保持一致。

第一轮真实测试因该服务返回 thinking 块而被保守拒绝，未执行任何工具；随后实现有序思考块、签名增量和 redacted 内容的保留回传，并新增确定性回归，再以新的验收任务完成上述闭环。完成 Job 全树退出确认后，再以独立任务复核同一真实工具闭环成功。失败任务未自动重试；累计 1 次失败请求及两次成功任务各 3 次请求。未公开地址、模型标识、凭据引用、思考内容或原始回复。

该结果只证明此次用户配置的 Anthropic 服务；其他真实提供方、模型、Responses/Chat Completions 远程端点仍未实测。模型请求取消也不保证代理上游计费立即停止。

## 迁移、资料与限制

使用用户 v2 数据库的 SQLite 一致性只读副本完成 2→3 迁移，核对工作区/服务/会话/回合数量、服务配置与凭据引用哈希、会话文本哈希保持；原数据库仍为 v2，未改用户正在使用的配置。实际原窗口保持运行。本次不声称已经升级用户原配置。

完整日志、隔离数据库、Worker 回执及截图在忽略的 `.tmp-troop-agent/`；任务界面最近一次成功报告由 `latest-agent-smoke.json` 指向。普通桌面报告仍在 `.tmp-troop-bootstrap/`。真实服务与迁移脚本只在本机使用，不随源码发布。

文件检查和内部队列不能阻止所有外部编辑或恶意宿主进程；Shell 是明确批准的宿主能力，不是 OS 沙箱。命令最大 60 秒，无脱离所有权的后台作业。尚未做长期压力、签名安装包、干净机器、Agent 记忆/扩展或正式桌面控制验收；不关闭完整版本门禁。
