    另外已进行人工 SQLite / 元数据 JSON / 固定根槽读取，以及独立执行原 artifact 中加密类的人工向量实验：正确密钥可恢复，错误密钥和篡改被拒绝。本次人工未知字段在二进制往返中保留、经 JSON 投影后丢失。因此必须留存原字节。

    • 完整性：完整 / 部分 / 无法恢复；执行状态：一律“仅历史，不续跑”。仅有文本时显示“部分 · 仅文本可读”。
    • 同来源、同旧 ID、同版本：跳过。相同 ID 内容变化：在同一会话下保留版本，当前版本不变，用户查看后选择。来源不同且缺少明确关联时，不能按文本相同自动合并。
    • 根记录要区分内容哈希与固定槽；未知来源不能仅凭解析失败就推断为加密。
    • 缺失的记录、未识别字段与原始密文保留在隔离资料中；密钥不进入中间导出或报告。
    • 生产实现还须验证真实历史、SQLite/WAL 一致快照、完整引用闭包、跨源 ID 关系和事务恢复；本演示没有证明这些能力。
